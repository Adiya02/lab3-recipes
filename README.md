# Лабораторная работа №3. Работа с файлами XML и JSON

**Вариант:** Информация о рецептах

Django-приложение для сохранения рецептов в файлы JSON/XML, загрузки файлов с проверкой валидности и просмотра содержимого всех файлов.

## Как запустить

1. Установить Python 3.10+
2. Открыть терминал в этой папке
3. Создать виртуальное окружение: `python -m venv venv`
4. Активировать: `venv\Scripts\activate` (Windows) или `source venv/bin/activate` (Linux/macOS)
5. Установить зависимости: `pip install -r requirements.txt`
6. Применить миграции: `python manage.py migrate`
7. Запустить: `python manage.py runserver`
8. Открыть http://127.0.0.1:8000/

## Функционал

- Ввод рецепта через форму с валидацией
- Сохранение в JSON и XML
- Загрузка файлов JSON/XML с проверкой валидности
- Безопасная генерация имён (UUID)
- Просмотр содержимого всех файлов
- Сообщение при отсутствии файлов
